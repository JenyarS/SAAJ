# UKH Connect

A web-based platform for university clubs and study groups at the University of Kurdistan Hewlêr (UKH).

## About the Project

UKH Connect aims to improve student collaboration by providing a centralized platform where students can discover campus clubs, receive announcements, and organize study groups.

## Main Features

- Student registration and login
- Student profiles and role-based access
- Club directory and membership management
- Club announcements
- Study group creation and joining with capacity limits
- Student, club leader, and administrator dashboards

## Technologies

- **Programming Language:** Java
- **Backend Framework:** Spring Boot
- **Frontend:** HTML, CSS, JavaScript, Thymeleaf
- **Architecture:** Layered MVC
- **Version Control:** Git & GitHub
- **Development Methodology:** Scrum
